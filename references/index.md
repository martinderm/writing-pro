## Weitere Referenzen (Links)

- Every, „AI Style Guides: How to Help AI Write Like You“ (Katie Parrott):

  <https://github.com/louisfb01/ai-engineering-cheatsheets/blob/main/Anti_Slop_AI_Writing_Guide.md> —
  Wortliste mit Cut-Test und Evidence-first-Workflow (Draft → Freeze → Review →
  einmal rewriten). Mechanik übernehmen, Modell-Empfehlungen ignorieren (altern schnell).

  <https://dev.to/eddieajau/teaching-ai-to-write-like-you-3aae> — Super-Prompt

  Dokument inklusive Stimm-Evolution.
